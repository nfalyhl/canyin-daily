==============================================
 餐饮日报 · 小红书采集机（志愿版）使用说明
==============================================
最后更新：2026-10-01


【这东西是干嘛的】
机主的电脑关机时，任何人都可以用自己的电脑临时当"采集机"，
把小红的餐饮新品笔记抓下来，结果会自动出现在网页上给大家看。


【为什么非得用你自己的电脑】
小红书只承认"真实浏览器 + 家庭宽带 IP"。
服务器（机房 IP）和没有界面的浏览器都会被它拦掉（我们实测过，
无头浏览器直接被判"安全限制"），所以只能靠真实电脑。就这么回事。


【开始之前，你需要】
  · 一台能上网的 Windows 电脑（用家里的宽带最好）
  · 大约 5 分钟
  · 手机上装好的"小红书"App（用来扫码）


------------------------------------------------
 三步搞定
------------------------------------------------

【第 1 步】装 Python（已经装过的直接跳到第 2 步）

  1. 打开 https://www.python.org/downloads/
  2. 点黄色的大按钮 "Download Python 3.x.x"，下载后双击安装
  3. 安装界面**最下面有个勾**，一定要勾上：
         Add python.exe to PATH
     这个勾非常重要，不勾后面会找不到 Python。
     勾好后点 "Install Now"，等它装完。
  4. 验证一下：按键盘 Win+R，输入 cmd 回车，在黑色窗口里输入：
         python --version
     如果显示 "Python 3.x.x"，就是装好了。


【第 2 步】运行采集机

  1. 把 xhs-volunteer-pack.zip 解压到任意文件夹（比如桌面）
  2. 进到那个文件夹，双击 start.cmd
  3. 第一次运行会自动装一个小依赖（大约十几秒），
     看到这一行就说明跑起来了：
         [*] 启动采集代理（这个窗口不要关；关掉就等于离线）

     ★ 这个黑窗口不要关。关掉 = 你下线了。


【第 3 步】去网页扫码

  1. 打开 https://www.canyindaily.dpdns.org/xhs.html
  2. 点「扫码登录」按钮
  3. 等 1 分钟左右，二维码会出现在**网页里**
  4. 用手机上的小红书 App 扫它，然后在手机上点确认
  5. 网页显示"已登录"就成了。之后点「立即采集」就能抓数据。


------------------------------------------------
 你会看到什么（免得你以为是坏了）
------------------------------------------------

  · 电脑上：只有一个黑窗口在滚日志。**不会有任何浏览器窗口弹出来**。
    这是正常的 —— 浏览器在后台隐身工作，二维码会传到网页上给你扫。
  · 网页上：采集机会显示成"在线"，二维码、结果条数都会实时更新。


------------------------------------------------
 常见问题
------------------------------------------------

Q1：双击 start.cmd 一闪就没了？
A ：说明没找到 Python。重装 Python 并勾上 "Add python.exe to PATH"。

Q2：提示依赖安装失败？
A ：网络问题，手动跑一次这个命令就行：
        python -m pip install websocket-client -i https://pypi.tuna.tsinghua.edu.cn/simple

Q3：提示"已经有一个采集代理在跑了"？
A ：你这台电脑上已经开过一个了，不用再开第二个。

Q4：网页上还是显示"采集机离线"？
A ：① 先看黑窗口是不是被关了；② 在网页点一下「刷新状态」；
     ③ 再等 10 秒（代理每 5 秒会报到一次）。

Q5：二维码一直不出现？
A ：点「扫码登录」之后需要等 30~60 秒（要在你电脑上启动一次浏览器）。
     如果超过 2 分钟还没有，把黑窗口里的最后几行日志发出来看看。

Q6：我要怎么停下来？
A ：直接关掉那个黑窗口；或者在任务管理器里结束 python 进程。


------------------------------------------------
 隐私与安全（可以放心）
------------------------------------------------

  · 扫码得到的登录状态只保存在**你自己的电脑**上（放在 pack 目录里的
    浏览器配置文件夹中），不会上传到服务器，我们也拿不到。
  · 包里带的是一个"受限令牌"：它只能用来"报个到、领指令"，
    没有推送/删除日报、查看用户资料的权限（这一点我们实测验证过：
    用它调管理接口会被拒绝）。
  · 采集到的内容（笔记标题 / 作者 / 点赞数 / 链接）本来就是公开展示的。


------------------------------------------------
 想卸载
------------------------------------------------
  直接删掉整个文件夹就行。它不会安装到系统里，不留垃圾。
